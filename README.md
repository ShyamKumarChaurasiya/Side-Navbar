# Side Navbar

An interactive sidebar navigation menu built using HTML and CSS. This project demonstrates how to create a toggleable sidebar with navigation links, social media icons, a background image, and smooth CSS transitions without using JavaScript.

## 📌 About the Project

The Side Navbar is a frontend practice project created to improve my understanding of HTML structure, CSS positioning, transitions, and interactive user interface design.

The sidebar opens and closes using an HTML checkbox and CSS selectors, demonstrating how interactive elements can be created without JavaScript.

## ✨ Features

- Toggleable sidebar navigation menu
- Hamburger menu icon to open the sidebar
- Close button to hide the sidebar
- Smooth CSS transitions and animations
- Navigation links with Font Awesome icons
- Social media icons
- Full-screen background image
- Transparent sidebar design
- Hover effects on navigation links and icons
- Interactive menu using HTML checkbox and CSS

## 🛠️ Technologies Used

- **HTML5** – Structure and content
- **CSS3** – Styling, positioning, and transitions
- **Font Awesome 6.4.0** – Icons
- **Google Fonts (Poppins)** – Typography

## 💡 How It Works

The sidebar uses an HTML checkbox to control its visibility.

- When the checkbox is checked, the sidebar moves into view.
- When the checkbox is unchecked, the sidebar moves outside the screen.
- CSS transitions provide smooth movement between these states.

This interaction is implemented using the CSS `:checked` pseudo-class and sibling selectors.

## 📱 Responsiveness

This project focuses on practicing sidebar navigation and CSS interactions. Dedicated responsive layouts for different screen sizes have not been implemented.
